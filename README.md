# KINGMAN — วิ่งเก็บกระดอง

เกมเว็บต้นแบบ React + Vite รองรับมือถือ/คอมพิวเตอร์ ใช้รูปคิงแมนที่ผู้ใช้ส่งมา มีระบบปัดซ้าย–ขวา เก็บกระดอง หลบก้อนหิน คะแนน สถิติสูงสุดในเครื่อง และเตรียมกระดานคะแนนออนไลน์ด้วย Supabase

## 1) ทดลองเล่นบนเครื่อง
1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตก ZIP แล้วเปิดโฟลเดอร์ `kingman-game` ใน VS Code หรือ Terminal
3. รันคำสั่ง `npm install`
4. รัน `npm run dev`
5. เปิด URL ที่ Vite แสดง (โดยปกติ `http://localhost:5173`)

## 2) เปิดระบบคะแนนออนไลน์ด้วย Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com/
2. เข้า SQL Editor แล้วคัดลอกเนื้อหาไฟล์ `supabase.sql` ไป Run
3. ไปที่ Project Settings > API (หรือหน้า Connect/API Keys ในหน้าตาใหม่) แล้วคัดลอก Project URL และ publishable/anon key สำหรับเว็บ ห้ามใช้ `service_role` key ในเว็บ
4. คัดลอก `.env.example` เป็นไฟล์ `.env` และใส่ค่าจริง:

```
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

5. รีสตาร์ต `npm run dev` เพื่อทดสอบ ระบบจะแสดง ONLINE เมื่อเชื่อมต่อและอ่านตารางได้

## 3) นำขึ้น Vercel
1. อัปโหลดโฟลเดอร์โปรเจกต์ขึ้น GitHub (อย่าอัปโหลดไฟล์ `.env` ที่มีค่าจริง)
2. เข้า https://vercel.com/ แล้วเลือก Add New > Project และ Import repository
3. Framework เลือก Vite (หรือให้ระบบตรวจจับอัตโนมัติ); Build Command `npm run build`; Output Directory `dist`
4. ใน Project Settings > Environment Variables เพิ่ม `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` ด้วยค่าจริงจาก Supabase
5. กด Deploy แล้วเปิด URL ที่ Vercel ให้มา
6. ถ้าเพิ่ม/แก้ Environment Variables หลัง Deploy ให้ Redeploy อีกครั้ง

## วิธีเล่น
- มือถือ: ปัดซ้าย/ขวาบนสนาม หรือแตะปุ่มซ้าย/ขวาใต้สนาม
- คอมพิวเตอร์: ใช้ปุ่มลูกศรซ้าย/ขวา หรือ A/D
- เก็บ 🐢 เพื่อเพิ่มจำนวนกระดอง; ชน 🪨 แล้วจบเกม

## ข้อจำกัดที่ควรรู้
- ถ้ายังไม่ตั้งค่า Supabase เกมยังเล่นได้ แต่กระดานคะแนนออนไลน์ไม่ทำงาน คะแนนสถิติส่วนตัวเก็บในเบราว์เซอร์เครื่องนั้น
- เวอร์ชันนี้เป็นโปรโตไทป์เพื่อเริ่มต้น ระบบรับคะแนนจากเบราว์เซอร์และไม่ใช่ระบบป้องกันโกงระดับแข่งขัน หากจะจัดรางวัลจริง ควรย้ายการตรวจสอบคะแนนไปฝั่งเซิร์ฟเวอร์ เพิ่มระบบจำกัดคำขอ และ/หรือระบบล็อกอิน
- ปุ่มเสียงเป็นตัวเลือก UI ในเวอร์ชันต้นแบบ ยังไม่มีเสียงประกอบเกม
- รูปคิงแมนหลักมาจากภาพที่แนบ และตัดพื้นหลังสีน้ำเงินออกโดยอัตโนมัติ อาจมีขอบบางส่วนที่ต้องเก็บเพิ่มหากต้องการงานภาพเนียนระดับโปรดักชัน
